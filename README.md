# 🌱 TERAWET® Automated Lead & Sales Outreach Agent

Повністю автоматизована система пошуку, кваліфікації та генерації персоналізованих B2B-пропозицій для суперабсорбенту **TERAWET®** ([terawet.eu](https://terawet.eu/)) по ринках **Болгарії, Румунії, Греції, Сербії та сусідніх країн**.

> **Ключова особливість (Human-in-the-loop):**  
> Всі листи генеруються автоматично рідною мовою клієнта (болгарська, румунська, грецька, англійська) і зберігаються **як чернетки (Drafts)** у вашій робочій пошті. Жоден лист не відправляється клієнту без вашої попередньої перевірки та натискання кнопки "Надіслати".

## ⚡ Швидкий старт за 1 хвилину (Тестовий запуск)

Система готова до запуску «з коробки» навіть без API ключів завдяки вбудованому демонстраційному генератору.

1. Перейдіть у папку проєкту:
   ```bash
   cd /Users/anastasiia/.gemini/antigravity/scratch/terawet_sales_agent
   ```
2. Запустіть агента:
   ```bash
   python3 main.py
   ```
3. Перевірте згенеровані чернетки:
   * Агент обробить контакти з `leads_sample.csv`.
   * Збереже готові чернетки в папці `drafts_preview/`.
   * Відкрийте будь-який `.html` файл у браузері (наприклад, румунський або грецький лист) та оцініть персоналізацію, норми внесення та вигоду!

## 🔑 Підключення живого ШІ (OpenAI або Gemini)

1. Створіть файл `.env` із шаблону:
   ```bash
   cp .env.example .env
   ```
2. Відкрийте `.env` і додайте ваш API ключ:
   ```env
   OPENAI_API_KEY=sk-proj-ваш_ключ_openai
   LLM_PROVIDER=openai
   LLM_MODEL=gpt-4o-mini
   ```
   *(або використовуйте `GEMINI_API_KEY`)*.
3. Скиньте статус лідів для повторного прогону:
   ```bash
   python3 main.py --reset
   python3 main.py
   ```
   Тепер кожен лист генеруватиметься нейромережею в реальному часі на основі бази знань `knowledge_base.json`.

## 📬 Підключення до вашого Gmail (Створення чернеток у пошті)

Щоб чернетки з'являлися безпосередньо у папці **"Чернетки" (Drafts)** вашого робочого акаунта Gmail/Google Workspace:

1. **Створіть безкоштовний проект у Google Cloud Console:**
   * Перейдіть на [console.cloud.google.com](https://console.cloud.google.com/).
   * Натисніть **Create Project** (наприклад, `terawet-outreach`).
2. **Увімкніть Gmail API:**
   * У меню перейдіть в **APIs & Services ➔ Library**.
   * Знайдіть **Gmail API** та натисніть **Enable**.
3. **Налаштуйте екран згоди (OAuth Consent Screen):**
   * Оберіть **External**, введіть назву (наприклад, `TeraWet Agent`) та свій email.
   * Додайте дозвіл (Scope): `https://www.googleapis.com/auth/gmail.compose` *(безпечний дозвіл — дозволяє створювати лише чернетки)*.
   * У розділі **Test Users** додайте свою поштову адресу Gmail.
4. **Створіть OAuth Client ID:**
   * Перейдіть в **Credentials ➔ Create Credentials ➔ OAuth Client ID**.
   * Тип додатку: **Desktop app**.
   * Завантажте JSON-файл і збережіть його в цій папці під назвою:
     `credentials.json`
5. **Увімкніть Gmail у файлі `.env`:**
   ```env
   GMAIL_ENABLED=true
   ```
6. **Запустіть скрипт:**
   ```bash
   python3 main.py
   ```
   * При першому запуску відкриється вікно браузера для одноразової авторизації вашого Gmail.
   * Після цього агент створить чернетки безпосередньо у вашому Gmail!

## 📊 Підключення Google Таблиці (Замість локального CSV)

Якщо ви ведете базу лідів у спільній Google Таблиці:

1. Створіть таблицю з такими стовпчиками:
   `company_name`, `website`, `country`, `language`, `segment`, `crops`, `contact_person`, `email`, `phone`, `status`, `draft_id`, `generated_subject`, `notes`.
2. Увімкніть **Google Sheets API** та **Google Drive API** у вашому Google Cloud проекті.
3. Створіть **Service Account**, завантажте ключ `service_account.json` у папку проєкту та поділіться таблицею з email цього сервісного акаунта (з правом редагування).
4. У `.env` встановіть:
   ```env
   DATA_SOURCE=google_sheets
   GOOGLE_SHEET_ID=ідентифікатор_вашої_таблиці_з_url
   ```

## 🔄 Використання через n8n (Візуальний конструктор)

Якщо ви віддаєте перевагу платформі **n8n**:
1. Відкрийте ваш n8n (Self-hosted або Cloud).
2. Натисніть **Workflows ➔ Import from file**.
3. Оберіть файл `terawet_n8n_workflow.json` із цієї папки.
4. Введіть ваші облікові дані для Google Sheets, OpenAI та Gmail.
5. Натисніть **Active** — воркфлоу запускатиметься автоматично за розкладом або за кліком!

## 🎯 Як відбувається щоденна робота менеджера

1. **Парсинг контактів**: раз на тиждень через Google Maps / Outscraper збираються нові контакти фермерів Румунії, Греції чи Болгарії (див. [`scraping_guide.md`](scraping_guide.md)) і вставляються в таблицю зі статусом `NEW`.
2. **Запуск агента**: скрипт або n8n аналізує кожного клієнта і генерує чернетки.
3. **Вичитка в пошті**: менеджер відкриває свій Gmail ➔ папку **«Чернетки»**, бачить уже заповнені листи рідною мовою клієнта з правильними дозуваннями TeraWet, витрачає 10 секунд на перевірку і натискає **«Надіслати»**.
